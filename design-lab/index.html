개발용 디자인 탐색 자료입니다. 메인 화면에서 링크하지 않으며, Pages가 branch root 구조라 배포물에도 함께 올라갑니다(비공개가 아님). 시안의 문구는 가짜 샘플입니다.

시안 (같은 Cobalt 토큰, 배치만 다름)

  • 시안 1 — 컴팩트 행
    한 화면에 많이 훑기. 행 높이 약 64px.
  • 시안 2 — 편안한 탐색 (채택, 현재 index.html)
    큰 제목, 넓은 행, 마감 임박 레일.
  • 시안 3 — 달력 우선
    월간 격자 중심, 선택한 날의 일정 패널.

조절판

  • playground — 강조색·간격·반경 슬라이더, CSS 변수 복사
