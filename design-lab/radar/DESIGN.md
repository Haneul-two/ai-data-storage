# AI Radar — 디자인 (채택안 A: 연속 비교 행 + 맥락 유지 상세)

> 루트 `design.md`가 프로젝트 공식 디자인 문서(AI Radar 요약·토큰·반응형)다. 이 문서는 그 세부 명세와 대안 비교다.

## 컨셉 한 문장
**레이더 화면처럼 "곧 끝나는 것"이 먼저 보이는 마감 중심 비교 목록.** 장식 대신 열 정렬·구분선·숫자로 읽는 전문가용 업무 도구. 처음 한 화면에서 검색 → 비교 → 상세로 이어지고, 설명·구호·히어로 영역은 없다.

## 토큰 (`tokens.css`가 유일한 원천)
| 구분 | 값 |
|---|---|
| 바탕 / 표면 | `#F6F7F5` / `#FFFFFF` |
| 본문 / 보조 | `#202622` / `#66706A` (보조 글자 대비 약 5:1) |
| 강조 | forest `#16604A` (hover `#0F4A39`, soft `#E6EFEA`) — 선택 상태·주요 행동에만 |
| 임박 | amber `#8A5A00` (soft `#FFF4DC`) — D-7 이내 마감, 경고에만 |
| 선 | `#DDE2DE` / 강조선 `#C5CCC7` |
| 반경 | 4 / 6px (pill 없음) |
| 글꼴 | 시스템 한국어 스택(기존 재사용), 날짜·건수는 `tabular-nums` |
| 모션 | 120ms(hover/선택), 160ms(상세 드로어 진입). `prefers-reduced-motion`에서 모두 제거 |
| 금지 | 그라디언트, 큰 그림자, 큰 영웅 문구, 유형별 색 배지, 장식 레이더 애니메이션, 외부 폰트·프레임워크 |

유형(행사/공모전/해커톤)과 상태는 **색이 아니라 글자**로 구분한다. 색은 "선택됨(forest)"과 "서둘러야 함(amber)" 두 의미에만 쓴다.

## 화면 구조
```
[60px 상단 바] AI Radar | 탐색 · 저장 N | 서울 오늘 · 데이터 갱신 | 새로고침
[44px 검색]  + 한 줄 범위 안내
[도구줄]     유형 탭(건수) · 결과 N건 / 진행 중 M건 · 정렬 · 목록/달력
[200px 필터] 진행 상태 · 참가 방식 · 초기화 · (접힘) 마감 임박 · 출처 상태   |   비교 목록(열 머리글 + 행)
```
- 행(데스크톱 96px~): `제목·주최·유형·상태·출처·마지막 확인 | 마감(D-day·시각 미확인) | 개최 | 방식·자격·상금 | 저장`. 제목은 줄바꿈하고 모든 칸 `min-width:0` + `overflow-wrap:anywhere`로 긴 URL이 넘치지 않는다.
- 반응형: 1280 이상 필터 200 고정 + 5열. 960~1279 필터 접힘·목록 전폭·4열(참가·상금 둘째 줄). 960 미만 라벨 있는 세로 행(제목 전체 너비 → 마감·개최 2열 → 참가·상금 → 저장 별도 행), 열 머리글 숨김. 360 미만은 마감·개최도 한 줄씩. 터치 목표 44px, 제목 폭 200px 이상을 320~1440에서 회귀 검사.
- 상세: 네이티브 `<dialog>` 오른쪽 드로어 540px(모바일 전체 화면). 포커스 가둠·Esc·닫은 뒤 행 제목으로 복귀. 원문은 "안내 페이지 열기"(집계 사이트를 공식 신청이라 부르지 않음).
- 오른쪽 마감 임박 레일은 제거(마감순 정렬과 중복). 마감 임박 목록·출처 상태는 필터 하단 접힌 details.

## 노출 규칙 (디자인 요건)
`assets/visibility.mjs`의 `isListed(item, now)` 하나가 목록·검색·유형/상태 건수·저장 건수·저장 보기·달력·마감 임박·상세 진입을 결정한다. 한국시간 현재 시각 기준 — exact 마감은 시각 이후 제외, 날짜만 있는 마감은 그날 23:59:59.999까지 노출하고 "마감 시각 미확인"을 표시, 마감 미확정 미래 행사는 유지. 시간이 흘러 마감이 지나면(15초 점검·탭 복귀) 목록과 열린 상세도 따라 정리되고 이유를 안내한다. 저장 id·원본 데이터는 지우지 않는다.

## 참조 근거 (구조만 참고, 복제하지 않음)
| 참조 | 가져온 것 |

| [Linear 필터](https://linear.app/docs/filters) · [피크](https://linear.app/docs/peek) | 목록을 유지한 조건 필터, 맥락을 잃지 않는 상세 |
| [Carbon 데이터 테이블](https://www.carbondesignsystem.com/building-blocks/core/components/data-table/guidelines) | 열 머리글·밀도·좁은 화면 변환 |

## 접근성
`<h1>` 시각 숨김 + 본문 바로가기, 제목 버튼이 상세 열기(행 빈 곳 클릭은 보조), 모든 선택 컨트롤 `aria-pressed`, 결과 건수·알림 `aria-live=polite`, 포커스 링 2px forest, 대비 4.5:1 이상, 키보드만으로 검색→저장→상세→달력 가능, 모바일 터치 44px, reduced-motion 지원, 색만으로 의미 전달하지 않음(D-day·"시각 미확인"은 글자).

| 안 | 장점 | 탈락/채택 이유 |
