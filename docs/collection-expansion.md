## 구현 범위

1. 공식행사 3개를 독립 소스 상태와 매일 재확인 경로로 연결. JSON-LD reader는 두 실제 사용처에서만 공유한다. NVIDIA hero 파서는 별도 모듈. 본문 연도/날짜를 읽고 구조가 달라지면 오류와 이전 데이터 보존으로 대응한다. 날짜를 코드에 고정하지 않는다.
2. 위비티 최대6페이지/100항목(목록15개씩 최대90)로 확장. URL은 AI 제목 검색을 유지하며 gp=2 등 다음페이지 사용. 항목 중복은 ix로 제거하고 빈/반복 페이지에서 중단. 기존 소스20 제한은 유지. 명시 --max-items 한도는 위비티에서도 적용한다. 단일 추가 페이지 오류를 숨기지 않는다.
3. 페스타·축제·festival·festa·AI Day 행사 분류를 보완. 해커톤 > 공모전 > 행사 우선순위와 강좌/채용 제외 규칙 유지.
4. 기존 UI/데이터계약/실패 보존/연락처 마스킹/HTTPS와 robots/15초timeout/1초요청간격/스케줄 유지. 지정된 공식사이트를 모니터링하며 웹 전체 행사 발견을 보장하지 않는다.
