# AI Radar 재설계·수집 확장 사양

사용자 요청: AI 티가 나지 않는 전문가용 탐색 디자인, GPT 6.1 SOL 최대 추론으로 검색·설계, 오늘 기준 신청 마감 제외, 수집 범위 최대 확장, 이름 AI Radar.
확인된 조건: 개인 참가 기회 탐색; 국내 전체와 한국에서 참가 가능한 해외 온라인; 공개 출처만, 로그인·차단 우회·유료 API 없음; 매일 갱신. 한국시간 현재 시각에 확정 마감 제외, 시각 없는 오늘 마감은 오늘까지 표시, 미확정 미래 행사 유지.

## P0

- 브랜드·브라우저 제목 AI Radar. 큰 홍보 영역 대신 검색과 비교 목록 우선. 제목·주최·참가 방식·신청/제출 마감·개최 일정을 비교 가능하게 배치한다.
- 현재 한국시간 기준 closed/ended 항목을 모든 탐색·검색·유형 건수·저장·달력·임박 목록·상세 진입에서 제외한다. 원본 및 보관 데이터는 삭제하지 않는다. 이전 status=closed URL/저장 설정은 안전한 기본값으로 변환한다.
- exact 마감은 현재 시각 이상이면 유효, 이후 제외. dateOnly는 한국시간 해당 날짜 끝까지 표시하고 시각 확인 필요를 유지. 마감 미확정은 신청 가능 확정이라고 표시하지 않는다. 참가 자격과 참가비를 추정하지 않는다.
- 공개 수집 출처와 목록 깊이를 재조사하고, robots 허용·재현 가능한 데이터 구조·정확한 기간 근거가 있는 출처를 추가한다. 수집 수 자체보다 실제 누락 발견 및 지속 갱신 가능성이 우선이다.

## P1

- 데스크톱 비교 목록, 390px 모바일 주요 정보 가독성, 필터·목록/달력·저장·상세·원문 링크·출처 신선도 상태 유지.
- 검색 입력 디바운스 및 포커스/캐럿 유지. 오류·빈 결과·로딩·새로고침 중복 방지. 키보드·Escape·포커스 복귀. 현재 시각이 바뀌면 마감 제외도 갱신한다.
- GPT 6.1 SOL(max) 디자인 조사 → Claude 기존 파일 구현 → Codex 독립 리뷰. 서로 다른 작업자 소유 파일을 침범하지 않는다.
- Python 및 Node 날짜/보안/부분 실패 회귀, 실제 공개 출처 수집, 실제 Edge 데스크톱·모바일 캡처 및 접근성/가로 넘침/검색/저장/달력/상세 검사.

## P2

- 사용자의 동작을 설명하는 짧은 필터/상세/저장 전환 효과. prefers-reduced-motion 지원. 장식용 자동 애니메이션과 무거운 라이브러리는 넣지 않는다.

## 분야 제약

- 기존 파일은 Claude가 편집한다. Codex는 새 문서·조사·실행·독립 리뷰를 수행한다(프로젝트 AGENTS).
- 기존 원본 데이터와 별도 checkout은 변경하지 않는다. robots·정확한 fetch 호스트·HTTPS·redirect 검증·요청 간격·타임아웃·응답 크기 상한을 유지해 무제한 요청과 우회를 방지한다.
- 개인정보·키는 코드/로그/JSON에 저장하지 않는다. 일부 출처 실패는 이전 항목과 검증 시각을 보존하고 실패 상태를 표시한다. 실행 LLM 토큰은 0을 유지한다.
- 수집/디자인 구현은 기능별 모듈로 나누고 사용자 요청과 관련된 부분만 수정한다. 자동 참가 신청·알림 발송·계정·DB·웹 전체 무제한 크롤러는 추가하지 않는다.

## 검증과 가정

- 테스트는 now를 주입해 오늘 마감/시각 직전·직후/한국시간 날짜 경계/취소/종료/마감 미정의 기대값을 고정한다.
- 실제 수집에서는 소스별 성공·실패·항목 수와 이전 값 보존을 독립 대조한다. 새 출처별 정상/변형/손상 HTML 픽스처를 최소화한다.
- localhost 디버그로 로딩·오류·빈 상태 및 날짜를 재현하고 공개 환경에서 디버그 무효를 유지한다.
- 디자인 방향은 정보 비교 중심의 전문 업무 도구로 결정한다. 구체 토큰과 구조는 조사 결과를 DESIGN.md에 반영한다.
- 원격 운영 반영은 기존 세션에서 승인한 보드 변경·배포 범위로 수행하되 코드/로컬 검증을 먼저 완료한다. 파일·브랜치 삭제 없음.
